# ShopNest - Simple E-commerce Store

ShopNest is a simple e-commerce web application developed as part of the CodeAlpha E-commerce Store Task.

## Project Description

ShopNest allows users to browse products, view product details, register and log in, add products to a shopping cart, and place orders through a checkout system.

The application uses Node.js and Express.js for the backend and PostgreSQL for database management.

## Features

- Product listing
- Product details page
- 15 products with images
- User registration
- User login and logout
- Password hashing using bcrypt
- Shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Checkout page
- Delivery address
- Order processing
- Order confirmation
- PostgreSQL database
- Responsive and professional UI
